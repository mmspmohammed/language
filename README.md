# 🎤 Chinese Pronunciation Trainer
تطبيق ويب لتعلم وتحسين نطق اللغة الصينية المبسطة (مع دعم الإنجليزية والفرنسية)

## ✨ المميزات
- 🎯 تقييم نطق دقيق باستخدام Whisper AI
- 📝 دعم 3 لغات: الصينية المبسطة، الإنجليزية، الفرنسية
- 📊 تحليل تفصيلي للأخطاء
- 🎧 استماع للنطق الصحيح
- 📈 تتبع التقدم
- 🧪 نظام اختبارات (قريباً)

## 🚀 التقنيات المستخدمة
- **Frontend:** Next.js 14, React, Tailwind CSS, shadcn/ui
- **Backend:** Next.js API Routes
- **Database:** Supabase (PostgreSQL + Auth)
- **AI:** OpenAI Whisper API
- **Speech:** Web Speech API
